# ECHO: ZERO PROTOCOL

A top-down sci-fi thriller built with Python and Pygame.

## Setup
```
python -m venv .venv
# Windows: .venv\Scripts\activate
# Mac/Linux: source .venv/bin/activate
pip install -r requirements.txt
python main.py
```

## Controls
- **WASD** — Move
- **Mouse** — Aim
- **Left Click** — Shoot
- **1/2** — Switch Weapon (Pulse Pistol / Arc Rifle)
- **Q** — EMP Blast (costs 30 energy)
- **E** — Interact (doors, terminals, recordings)
- **F** — Flashlight
- **TAB** — Inventory
- **ESC** — Pause Menu

## Features
- 3 Enemy types with unique FSM AI and A* pathfinding
- Player behavior tracking + adaptive ECHO AI companion
- Branching story with 2 endings (Liberation / Containment)
- Full inventory, save/load, and dialogue systems
- Procedural audio — all SFX and music synthesized from waveforms
- 2 chapters with hand-designed tile maps
